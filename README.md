# Calculadora full-stack (React + Go)

Calculadora web para una prueba técnica. El frontend va a estar en React con TypeScript y las operaciones las resuelve un microservicio en Go.

Por ahora está la lógica de las operaciones en Go: suma, resta, multiplicación, división, potencia, raíz cuadrada y porcentaje, cada una con sus pruebas.

## Pruebas

```bash
cd backend
go test ./...
```
